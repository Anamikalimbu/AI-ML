# Student Performance Data Analysis

A small Python data analysis project using pandas, NumPy, and Matplotlib.

## What it does
- Generates a sample dataset of 200 students (study hours, attendance, sleep hours, score)
- Prints summary statistics and checks for missing values
- Computes correlations with the score
- Compares average scores across low / medium / high study levels
- Saves charts (score distribution, study hours vs score, correlation heatmap) to `analysis_results.png`

## Run
```bash
pip install -r requirements.txt
python student_performance_analysis.py
```
