# Day 1 - AI Email Marketing Funnel

## Objective
Create an AI-powered email marketing workflow using Mailchimp and Zapier.

## Tools Used
- Mailchimp
- Zapier
- Gmail
- ChatGPT

## Workflow

Mailchimp (New Subscriber)
↓
Zapier Automation
↓
Gmail (Welcome Email)

## Outcome
Whenever a new subscriber is added to Mailchimp, Zapier automatically sends a welcome email through Gmail.
