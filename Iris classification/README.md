# Iris Flower Classification

A beginner-friendly machine learning project using scikit-learn.

## What it does
- Loads the built-in Iris dataset (no download needed)
- Compares KNN, Logistic Regression, Decision Tree, and Random Forest with 5-fold cross-validation
- Evaluates the best model on a held-out test set (accuracy, classification report, confusion matrix)
- Saves charts to `classification_results.png`

## Run
```bash
pip install -r requirements.txt
python iris_classification.py
```
